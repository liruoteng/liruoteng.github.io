One desktop loop

Write, inspect, revise, ship.

Type Studio is organized around panels you can open, close, and reorder: editor, preview, outline, AI, diff, and PDF viewer. It is meant for repeated authoring work, not a maze of disconnected tools.

01

Open a workspace

Use the file tree to manage Typst, Markdown, BibTeX, and paper assets.

02

Draft with feedback

Write with Monaco, slash commands, language features, and live rendered output.

03

Bring in help

Use AI sessions, references, and templates where they support the writing.

04

Export the result

Compile through the app and save a polished PDF when the document is ready.
